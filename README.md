# 🚀 GoCore API

Современный backend-сервис, написанный на Go.  
Проект демонстрирует базовую архитектуру серверного приложения, работу с HTTP, роутингом и организацией кода.

## 📌 О проекте

Этот проект был создан в рамках обучения и практики Go-разработки.  
Основная цель — изучить:

- создание REST API
- работу с HTTP-сервером
- структуру backend-приложения
- обработку запросов и ответов
- организацию чистого кода

## ⚙️ Технологии

- Go (Golang)
- net/http
- JSON
- REST API

## 📁 Структура проекта
/cmd        # точка входа
/internal   # бизнес-логика
/pkg        # переиспользуемые пакеты
/api        # обработчики (handlers)
